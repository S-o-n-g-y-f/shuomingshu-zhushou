# 样张收集说明（评测用）

这个目录放评测样张。**此目录整体不进公开仓库**（见仓库根 .gitignore），只公开评测统计结果。

## 一、文字样张（现在就能收，宿舍可完成）

用途：评测字段抽取层（药名 / 规格 / 用法用量 / 频次 / 禁忌 / 严重警示）。

- 来源：丁香园用药参考、厂家官网、国家药监局数据查询。搜「药名 + 说明书」。
- 每个药一个 txt：`药名_规格.txt`，例如 `阿莫西林胶囊_0.25g.txt`
- 内容要求：**完整说明书**，从「药品名称」到「批准文号」，不截取
- 文件第一行写来源，例如：`<!-- 来源：丁香园用药参考 -->`
- 数量目标：20 个；建议覆盖降压、降糖、感冒退烧、维生素、眼药水、外用药各几样
- 挑选原则：优先 OTC（网上最全）；避开已知极冷门、网上无全文的品种

## 二、照片样张（等 OCR 接上后收，可回家或让家人帮拍）

用途：评测 OCR 层。照片追求"真"：反光、弧面、小字都保留，这是 OCR 的难活。

- 拍有药名和规格的那一面；光线亮、对焦清楚
- **脱敏**：照片中不得出现姓名、电话、病历号、医保号（药盒贴了名字贴纸的，涂掉再拍）
- 文件名：`photo_01.jpg` … `photo_20.jpg`，并在 index.csv 里登记对应药名

## 三、登记表 index.csv

每收一份登记一行，列：

```
文件名,药名,规格,厂家,来源,类型(文字/照片),登记日期
```
